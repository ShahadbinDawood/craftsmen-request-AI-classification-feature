# نظام تصنيف طلبات الصيانة بالذكاء الاصطناعي

ميزة تربط المستخدمين بفنيين الصيانة (سباكة، كهرباء، نجارة، تكييف...) — يكتب المستخدم مشكلته بلغة طبيعية، والنظام يصنفها تلقائيًا (النوع + الأولوية) باستخدام Claude API، مع إمكانية التعديل قبل الحفظ.

## أدوات AI المستخدمة

- **Claude (Anthropic)** — استخدمته كمساعد برمجي طوال المشروع لـ:
  - بناء بنية الباك إند (Express + routes + services)
  - كتابة الـ prompt الخاص بالتصنيف والفصل بين المشاكل المتعددة
  - حل مشاكل ترميز UTF-8 وأخطاء ESM/CommonJS
  - تحسين واجهة المستخدم (Tailwind + مراجعة UX)
- **Claude API** كخدمة تصنيف فعلية داخل التطبيق (مو أداة تطوير فقط) — هو المحرك اللي يفهم وصف المشكلة ويصنفها.

## المتطلبات

- Node.js 18+
- مفتاح Anthropic API

## خطوات التشغيل محليًا

### Backend

```bash
cd backend
npm install
```

أنشئ ملف `.env` بداخل مجلد `backend` واضف:

```
ANTHROPIC_API_KEY=your_key_here
PORT=3001
```

```bash
npm run dev
```

السيرفر يشتغل على http://localhost:3001

### Frontend

```bash
cd frontend
npm install
npm run dev
```

الواجهة تشتغل على http://localhost:5173

## القرارات التقنية

- **Backend: Node.js + Express** بدل Spring Boot — سرعة تطوير أعلى لحجم المشروع خلال المدة المتاحة.
- **Claude API مباشرة من الباك إند فقط** — المفتاح محفوظ بـ `.env` وما يوصل للفرونت إند إطلاقًا؛ الفرونت يكلم `/api/classify` فقط.
- **فصل `/api/classify` عن `/api/requests`** — تصميم مقصود يطابق المتطلب رقم 2 بالسيناريو (إمكانية التعديل قبل التأكيد النهائي). التصنيف لا يحفظ تلقائيًا.
- **الفصل بين المشاكل المتعددة يتم داخل الـ AI نفسه** (structured JSON output) بدل منطق تقسيم منفصل بالكود.
- **SQLite (better-sqlite3)** للتخزين — sync وسريع، وسهل التوسع.
- **تحقق من وضوح الوصف** — الـ prompt نفسه يرفض النصوص الغامضة/العشوائية ويرجع رسالة خطأ واضحة.
- **React + Vite + Tailwind CSS** للفرونت إند — تصميم mobile-first.
- **Rate limiting على `/api/classify`** (10 طلبات/دقيقة لكل IP) — حماية من إساءة استخدام مفتاح Claude API المدفوع، ومنع استنزاف الحصة (quota) بطلبات متكررة أو آلية.
