# نظام تصنيف طلبات الصيانة بالذكاء الاصطناعي

ميزة تربط المستخدمين بفنيين الصيانة (سباكة، كهرباء، نجارة، تكييف...) — يكتب المستخدم مشكلته بلغة طبيعية، والنظام يصنفها تلقائيًا (النوع + الأولوية) باستخدام Claude API، مع إمكانية التعديل قبل الحفظ.

## أدوات AI المستخدمة

- **Claude (Anthropic)** — استُخدم كمساعد برمجي طوال المشروع في:
  - بناء بنية الباك إند (Express + routes + services)
  - كتابة الـ prompt الخاص بالتصنيف والفصل بين المشاكل المتعددة
  - حل مشاكل ترميز UTF-8 وأخطاء ESM/CommonJS
  - تحسين واجهة المستخدم (Tailwind + مراجعة UX)
- **Claude API** كخدمة تصنيف فعلية داخل التطبيق (وليس أداة تطوير فقط) — هو المحرك الذي يفهم وصف المشكلة ويصنفها.

## المتطلبات

- Node.js 18+
- مفتاح Anthropic API

## خطوات التشغيل محليًا

### Backend

```bash
cd backend
npm install
```

إنشاء ملف `.env` داخل مجلد `backend` وإضافة:

```
ANTHROPIC_API_KEY=your_key_here
PORT=3001
```

```bash
npm run dev
```

السيرفر يعمل على http://localhost:3001

### Frontend

```bash
cd frontend
npm install
npm run dev
```

الواجهة تعمل على http://localhost:5173

## القرارات التقنية

- **Backend: Node.js + Express** بدل Spring Boot — سرعة تطوير أعلى لحجم المشروع خلال المدة المتاحة.
- **Claude API مباشرة من الباك إند فقط** — المفتاح محفوظ في `.env` ولا يصل للفرونت إند إطلاقًا؛ الفرونت يتواصل مع `/api/classify` فقط.
- **فصل `/api/classify` عن `/api/requests`** — تصميم مقصود يطابق متطلب المواصفات (إمكانية التعديل قبل التأكيد النهائي). التصنيف لا يُحفظ تلقائيًا.
- **الفصل بين المشاكل المتعددة يتم داخل الـ AI نفسه** (structured JSON output) بدل منطق تقسيم منفصل في الكود.
- **SQLite (better-sqlite3)** للتخزين — سريع، متزامن (sync)، وسهل التوسع.
- **تحقق من وضوح الوصف** — الـ prompt نفسه يرفض النصوص الغامضة/العشوائية ويعيد رسالة خطأ واضحة.
- **React + Vite + Tailwind CSS** للفرونت إند — تصميم mobile-first.

## أشياء ناقصة أو قابلة للتحسين

- Loading skeletons بدل نص "جاري التحميل" البسيط

- دعم رفع صور مع الطلب وتحليلها عبر Claude Vision
